# Python Intermediate 🐍🐍

A 12-day course (1 hour a day) for students who finished the **basic** course.
It covers the Python topics of the Class 10 syllabus (CDC Nepal).

## How each class works
1. **Teacher demo (~15 min):** run the code cells one by one and explain.
2. **Your Turn (~40 min):** students click a task, press **B** to add a code cell, and solve it.

⭐ easy · ⭐⭐ medium · ⭐⭐⭐ bonus (if you finish early)

Stuck? Every task has a hidden **💡 Need help?** section with the steps to solve it.

## Classes

| Day | Topic |
|---|---|
| 1 | Quick revision |
| 2 | Functions: `def`, parameters |
| 3 | `return`, default values, scope |
| 4 | Tuples and sets |
| 5 | Nested data and nested loops |
| 6 | Errors: `try` / `except` |
| 7 | Files: read, write, append |
| 8 | Turtle: moving and shapes |
| 9 | Turtle: colours and patterns |
| 10 | Pandas: tables and CSV files |
| 11 | Filtering data and charts (matplotlib) |
| 12 | Final project: report card system |

## Before the class
- **Days 8–9:** turtle opens a drawing window. Use Jupyter or VS Code on a computer (not Google Colab).
- **Days 10–12:** install the libraries once: `pip install pandas matplotlib`
- **Day 11, last task:** uses `marks.csv` made on Day 10, so keep the notebooks in the same folder.
